# 🩸 Blood Bank Management System

## 📖 Overview

The Blood Bank Management System is a Java-based application designed to manage blood donor details, blood stock, and patient requests efficiently. This system helps blood banks maintain records digitally and improves the speed and accuracy of operations.

---

## ✨ Features

- Donor Registration
- Add Blood Details
- View Blood Stock
- Search Donor Information
- Update Donor Details
- Delete Records
- Manage Blood Availability

---

## 🛠️ Technologies Used

- Java
- MySQL (Database)
- JDBC
- Swing / AWT (GUI)
- NetBeans / Eclipse IDE

---

## 🎯 Objective

The main objective of this project is to automate blood bank operations and maintain blood records efficiently, reducing manual errors and saving time.
